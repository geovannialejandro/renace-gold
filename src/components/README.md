# Components Directory

This directory contains reusable React components.

## Structure

- `common/` - Shared UI components (buttons, modals, cards, etc.)
- `layouts/` - Page layouts
- `features/` - Feature-specific components

## Guidelines

1. Each component should be in its own file
2. Use TypeScript interfaces for props
3. Export component and its types from index.ts
4. Include JSDoc comments for complex components
